# 代码与伪代码提取规则

本文档定义从论文 PDF 中定位、判定、转录代码区块的规则，以及开源链接的识别规范。核心原则：**原样转录，宁可漏标不可错改**。

## 代码区块定位信号

优先级从高到低：

1. **显式标记**：Algorithm 编号框（`Algorithm 1: ...`）、代码清单（Listing 1、Code 1）、等宽字体的框装区域。
2. **版式信号**：行首多级缩进 + 行号、`\begin{algorithm}` 排版特征（顶横线+底部横线）、行宽明显短于正文的连续块。
3. **语言线索**：`def `、`class `、`for `、`while `、`#include`、`void `、`function`、`:=`、`←`、`end if`、`end for` 等。
4. **上下文线索**：句子中出现 "as shown in Listing X"、"the pseudo-code of Algorithm X"、"implementation is available at"。

## 判定规则

| 信号 | 判定 |
|------|------|
| 有语言关键词结构 + 缩进 + 行号/边框 | 代码区块 |
| `←`、`:=`、`end if`、自然语言混合 | 伪代码，标注 `伪代码`，禁止转写为任何语言 |
| 数学推导（大量 `$`/上下标/希腊字母成行） | 不是代码，排除 |
| 表格（列对齐 + 表头） | 不是代码，排除 |
| 超过 3 行且代码符号密度 ≥ 0.4 的等宽块 | 候选代码，进入人工复核 |

**跨页拼接**：代码块被分页截断时，跨页拼接后标注 `跨页拼接（P3-P4）`；页眉页脚混入的行（期刊名、页码、会议名）必须剔除，剔除动作记录在排除清单中。

**截断不完整**：论文本身只展示片段（省略号、`...`、注释"完整代码见附件/仓库"）时原样保留省略标记，禁止补全。

## 转录铁律

- 保留原始缩进（空格/Tab 原样）；PDF 提取时 Tab 可能退化为空格，以可辨识的最小一致单位恢复，并在排除清单注明"缩进经恢复"。
- 保留原语言标注；无法判定语言时标注 `未知语言（原文未标注）`，禁止猜测。
- 数学符号（`←`、`∀`、`∃`、希腊字母）在伪代码中原样保留 Unicode 形式。
- 行号若论文原文有则保留为代码块前的独立行号列，不混入代码本体。

## 开源链接识别

扫描全文（含脚注、参考文献、致谢）中的仓库链接：

- 匹配模式：`github.com/<owner>/<repo>`、`gitlab.com/<owner>/<repo>`、`gitee.com/<owner>/<repo>`、匿名仓库短链（`anonymous.4open.science`、`gitee.com/anonymous`）。
- 每条链接记录：页码、原文上下文一句话、URL 原文形式。
- 项目主页（`project-page` 类）与代码仓库分开归类；数据集主页不算代码链接。
- 论文宣称"代码将开源/即将发布"但无 URL 时，报告中如实标注"论文声称代码将开源，未给出链接"，不算"已提供源码"。

## 依赖识别规则（提取代码时）

提取代码片段时同步识别其外部依赖，写入代码块的"依赖"字段：

- **Python**：`import X` / `from X import` 语句 → 记录顶层包名；区分标准库（math、os）与第三方（torch、numpy、open3d、ros2）。
- **C++**：`#include <X>` 区分标准库（`<...>`）与项目内头文件（`"..."`）；`CMakeLists.txt`/`package.xml` 片段记录为构建依赖。
- **MATLAB**：工具箱函数（`ode45`、`fmincon`）标注所属工具箱。
- **ROS 系代码**：识别话题（topic）订阅/发布、消息类型（`sensor_msgs/PointCloud2`）——这些是模块依赖关系的直接证据，优先用于架构图连线。
- 依赖只登记不安装、不验证版本兼容性。

## 未提供源码的标注格式

全文（含脚注与参考文献）检索仓库链接无结果时，报告代码章节顶部标注：

```markdown
> **⚠️ 论文未提供源码**
> 依据：全文（含脚注与参考文献，共 N 页）检索 github.com / gitlab.com / gitee.com 及
> "code is available" 类表述，均无结果。以下代码区块转录自论文正文中的伪代码/片段。
```
